## Publicação

O site publicado é estático: `index.html`, `assets/site.css` e `assets/site.js`, com logo otimizada, páginas de privacidade e erro 404. **Não requer servidor Node.js na produção.**

No GitHub, use **Settings → Pages → Deploy from a branch → main → /(root)**.

## Edição

Os arquivos HTML, CSS e JavaScript publicados podem ser alterados diretamente. O pacote original de desenvolvimento em Node.js, com configuração centralizada e scripts de geração, foi entregue separadamente ao responsável pelo projeto.
